## Troubleshooting

Installer error codes are documented with plain-language fixes in
[Troubleshooting](../guides/troubleshooting.md). It covers all 16 codes the
installer can print, including what each one means and the exact command to fix
it.

```powershell
./install.ps1 --self-test    # check the installer itself works
doctor                        # check your installed setup is healthy
```
